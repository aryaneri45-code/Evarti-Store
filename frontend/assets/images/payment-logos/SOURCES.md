# Payment logo sources

Each mark is stored locally so the footer does not depend on a third-party image host.

- `mastercard.svg` — [Current Mastercard symbol](https://commons.wikimedia.org/wiki/File:Mastercard_2019_logo.svg), using Mastercard's red, orange, and yellow overlapping circles.
- `visa.svg` — [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 icon artwork; Visa owns its trademark.
- `qris.svg` — [Bank Indonesia QRIS logo](https://commons.wikimedia.org/wiki/File:QRIS_logo.svg), sourced from Bank Indonesia material and marked public domain on Wikimedia Commons.
- `gopay.svg` — [GoPay official media kit](https://gopay.co.id/media-kit), horizontal SVG from the Logo Assets archive.
- `ovo-white.png` — [OVO official website](https://www.ovo.id/), site logo asset, shown on OVO's purple brand color.
- `shopeepay.svg` — [ShopeePay official brand guidelines](https://product.shopeepay.co.id/products/brand-guidelines), orange-on-white online acceptance mark.
